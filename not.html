$$a^n = \underbrace{a \cdot a \cdot \dots \cdot a}_{n \text{ tane}}$$ $$a^1 = a$$ $$a^0 = 1 \quad (a \neq 0)$$ $$1^n = 1$$ $$0^n = 0 \quad (n > 0)$$ $$a^{-n} = \frac{1}{a^n}$$ $$\left(\frac{a}{b}\right)^{-n} = \left(\frac{b}{a}\right)^n$$ $$a^{\frac{m}{n}} = \sqrt[n]{a^m}$$ $$a^n \cdot a^m = a^{n+m}$$ $$\frac{a^n}{a^m} = a^{n-m}$$ $$a^n \cdot b^n = (a \cdot b)^n$$ $$\frac{a^n}{b^n} = \left(\frac{a}{b}\right)^n$$ $$(a^n)^m = a^{n \cdot m} = (a^m)^n$$ $$a^x = a^y \implies x = y \quad (a \notin \{-1, 0, 1\})$$ $$x^n = y^n \implies x = y \quad (n = 2k+1)$$ $$x^n = y^n \implies x = \pm y \quad (n = 2k)$$
$$\sqrt[n]{a^m} = a^{\frac{m}{n}}$$ $$\sqrt[2n]{x^{2n}} = \vert{}x\vert{}$$ $$\sqrt[2n+1]{x^{2n+1}} = x$$ $$a\sqrt[n]{x} \pm b\sqrt[n]{x} = (a \pm b)\sqrt[n]{x}$$ $$\sqrt[n]{a} \cdot \sqrt[n]{b} = \sqrt[n]{a \cdot b}$$ $$\frac{\sqrt[n]{a}}{\sqrt[n]{b}} = \sqrt[n]{\frac{a}{b}}$$ $$\sqrt[n]{a^m} = \sqrt[n \cdot k]{a^{m \cdot k}}$$ $$\sqrt[n]{\sqrt[m]{a}} = \sqrt[n \cdot m]{a}$$ $$\sqrt{a \pm 2\sqrt{b}} = \sqrt{x} \pm \sqrt{y} \quad (x + y = a, \; x \cdot y = b, \; x > y)$$ $$(\sqrt{a} - \sqrt{b})(\sqrt{a} + \sqrt{b}) = a - b$$ $$\sqrt{a + \sqrt{a + \sqrt{a + \dots}}} = \frac{1 + \sqrt{1 + 4a}}{2}$$ $$\sqrt{a + \sqrt{a + \sqrt{a + \dots}}} = \frac{1 - \sqrt{1 + 4a}}{2}$$ $$\sqrt[n]{x \cdot \sqrt[n]{x \cdot \sqrt[n]{x \cdot \dots}}} = \sqrt[n-1]{x}$$ $$\sqrt{x \div \sqrt{x \div \sqrt{x \div \dots}}} = \sqrt[3]{x}$$
$$(a + b)^2 = a^2 + 2ab + b^2$$ $$a^2 - b^2 = (a - b)(a + b)$$ $$(a + b + c)^2 = a^2 + b^2 + c^2 + 2(ab + ac + bc)$$

$$A \cup B = \{x \mid x \in A \lor x \in B\}$$ $$A \cap B = \{x \mid x \in A \land x \in B\}$$ $$A \setminus B = \{x \mid x \in A \land x \notin B\}$$ $$A^\complement = U \setminus A = \{x \mid x \in U \land x \notin A\}$$ $$A \cup B = B \cup A$$ $$A \cap B = B \cap A$$ $$(A \cup B) \cup C = A \cup (B \cup C)$$ $$(A \cap B) \cap C = A \cap (B \cap C)$$ $$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$ $$(A \cup B)^\complement = A^\complement \cap B^\complement$$ $$A \triangle B = (A \setminus B) \cup (B \setminus A) = (A \cup B) \setminus (A \cap B)$$ $$A \times B = \{(a, b) \mid a \in A \land b \in B\}$$ $$s(A \cup B) = s(A) + s(B) - s(A \cap B)$$ $$s(A \times B) = s(A) \cdot s(B)$$
